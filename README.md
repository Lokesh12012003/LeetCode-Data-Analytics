# LeetCode-Data-Analytics

## 📌 Project Overview 

This project focuses on analyzing LeetCode data using Python for data cleaning and preprocessing, followed by Microsoft Power BI for data visualization and dashboard development.

The objective is to transform raw data into a clean, structured format and present meaningful insights through an interactive dashboard. This project demonstrates my practical skills in data preparation, data analysis, and visualization.

## 🎯 Project Objectives

Clean and preprocess raw data using Python.

Handle missing values, duplicates, and data inconsistencies.

Prepare structured data for visualization.

Build an interactive dashboard using Power BI.

Identify patterns and insights from the available data.

## 🛠️ Tools & Technologies
Python – Data cleaning and preprocessing

Pandas – Data manipulation and cleaning

Microsoft Power BI – Dashboard development and data visualization

## 🔄 Project Workflow
Data Preparation: Load and inspect the raw dataset using Python.

Data Cleaning: Handle missing values, duplicates, and inconsistent data.

Data Transformation: Organize the cleaned data into a suitable structure.

Data Visualization: Import the cleaned dataset into Power BI.

Dashboard Development: Create visualizations to explore the data and communicate key insights.

## 📊 Key Features

Cleaned and organized dataset.

Interactive Power BI dashboard.

Visual representation of key metrics and trends.

Data-driven insights to support better understanding of the dataset.

Analytical Thinking

## 🚀 Project Outcome
Successfully developed a data analytics workflow using Python and Power BI, converting raw data into a cleaned dataset and an interactive dashboard for easier analysis and interpretation.
